# Channel Management

## Chức năng

- Quản lý danh sách channel cần theo dõi.
- Add / Edit / Delete channel.
- Enable / Disable tracking.

## Lưu thông tin

- Channel Name
- Channel ID
- Channel URL
- Status
- Created Date
- Last Sync Time

## Liên quan

- Channel là input đầu vào cho [`discovery-engine.md`](discovery-engine.md).
- Cấu hình `MaxTrackingVideosPerChannel` xem ở [`../config.md`](../config.md).
